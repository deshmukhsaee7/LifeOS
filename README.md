# LifeOS — Your Personal Workspace

**Make space for the life you want.**

LifeOS is a personal productivity web application designed to bring everyday planning into one place. It helps users organize tasks, build habits, set goals, keep track of events, and understand their progress.

## Live Demo

[Visit LifeOS](https://lifeos-workspace7.netlify.app)

## Features

- **Personal dashboard** — Get an overview of daily activity and progress.
- **Task manager** — Create, prioritize, complete, and manage tasks.
- **Habit tracker** — Track daily habits and build consistency.
- **Goals and milestones** — Set personal goals and track progress through optional milestones.
- **Calendar** — Keep track of upcoming events.
- **Analytics** — View a summary of productivity and progress.
- **Personalization** — Customize the theme, accent colour, and layout.
- **Authentication** — Sign up and sign in using email or Google.
- **Cloud storage** — Save personal tasks, habits, goals, and events with Supabase.

## Built With

- HTML
- CSS
- JavaScript
- [Supabase](https://supabase.com/) — Authentication and database
- [Netlify](https://www.netlify.com/) — Hosting and deployment

## Security

LifeOS uses Supabase Row Level Security (RLS) policies to restrict access to each user's own records.

The frontend uses a Supabase publishable key. Secret/service-role keys must never be exposed in frontend code or committed to this repository.

## About the Project

LifeOS is a personal web development project created to explore frontend development, authentication, database integration, and deploying a functional web application.
